# Application internationalization

## Product decision

RemeMate's interface language is a separate preference from both language-learning
settings:

- **Interface language (`ui_locale`)** controls navigation, buttons, forms, system
  feedback, and help text. The first supported locales are Chinese (`zh`) and
  English (`en`).
- **Learning language (`current_language` / `learning_languages`)** controls which
  vocabulary, reviews, writing prompts, and reading material the user is working
  with.
- **Native / feedback language (`feedback_language`)** controls the language used
  for explanations and AI feedback.

Changing one must never mutate either of the others.

## Architecture

- `app/i18n.py` resolves one locale per request and exposes `_()` to Jinja.
- `app/translations/{zh,en}.json` are the authoritative catalogs. Catalogs must have
  identical keys; the coverage test enforces this.
- Authenticated choices persist in `user_settings.ui_locale`; the session carries
  the immediate choice and supports logged-out pages. With no explicit choice,
  browser `Accept-Language` is used, then Chinese as the final fallback.
- `/ui-language` changes only the interface and returns to the current safe local
  URL. `/language/switch` remains the learning-language switch.
- HTMX fragments use the same request locale and therefore render in the selected
  interface language without client-side DOM translation.

## Translation sequence

1. Foundation and daily shell: navigation, login, home review, daily tasks, settings. **Done.**
2. Output loop: compose, correction states, history, square. **Done.**
3. Vocabulary loop: vocabulary, word detail/edit, manual add, text extraction, CSV. **Done.**
4. Partner loop: partners, recaps, packets, feedback adoption. **Done.**
5. Reading and administration, then a whole-template untranslated-text audit.

Each batch should add catalog keys, migrate complete user workflows rather than
isolated labels, add Chinese/English integration assertions, and visually inspect
desktop and mobile layouts before it is merged.

## Canonical English terms

| Chinese | English | Notes |
| --- | --- | --- |
| 写一写 | Write | Product domain containing compose, history, and square |
| 造句 | Compose | The act of writing one target-language sentence |
| 广场 | Square | Public user-published writing; deliberately secondary |
| 生词本 | Vocabulary | The user's remembered words, not a generic library |
| 阅读收词 | Collect from reading | Reading is an intake path, not a full reader product |
| 语言伙伴 | Partners | Strong, account-bound language-exchange relationships |
| 复盘 | Recap | A private structured record of one exchange session |
| 反馈包 | Feedback | An immutable selected subset sent to a partner |
| 母语 | Native language | Used for explanations/AI feedback, not UI locale |
| 界面语言 | Interface language | Navigation and system copy only |
