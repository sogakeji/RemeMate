# 句子广场 设计文档

> 记录日期：2026-06-22
> 状态：设计完成，待实现（P2 社交功能）

---

## 一句话定义

用户每日造句（/write）产生的 AI 修正句，经用户选择公开后进入「句子广场」，社区用「夯」点赞投票，高票句自动成为该词的社区推荐例句。

---

## 数据流

```
SRS 选出到期词 X
    ↓
用户在 /write 围绕词 X 造句
    ↓
DeepSeek 批改 → 返回 {corrected, translation, feedback, is_nsfw}
    ↓
用户选择是否公开（is_nsfw=true 时公开按钮静默隐藏）
    ↓
公开 → 修正句进句子广场，携带 word_id（天然绑定，无需额外标注）
    ↓
其他用户点「夯」
    ↓
夯票最多且达到动态门槛 → 成为词 X 的社区推荐例句
```

---

## 核心设计决策

### 1. 来源与词句绑定
- 句子来自 `/write` 每日造句，由 SRS 到期词触发
- **词句天然绑定**：造句目标词即 `word_id`，无需用户手动标注

### 2. 广场展示内容
- 只展示 **AI 修正句**（不展示用户原句）
- 同时展示**母语翻译**（DeepSeek 批改时同一次 API 调用生成，不额外烧 token）
- 卡片结构：
  ```
  [目标语言修正句]  Le décollage m'a coupé le souffle.
  [母语翻译]        飞机起飞的瞬间让我屏住了呼吸。
  词：décollage · @用户名 · 🔥 12 夯
  ```

### 3. 评分系统
- **单维度「夯」**，纯正向点赞，无负面/中性标签
- 用户不想点就划走，零压力

### 4. 推荐规则
- 该词夯票最多的句子进入导词推荐池
- **动态门槛**随用户规模调整：

  | 每语言组活跃用户 | 最低夯票门槛 |
  |---|---|
  | < 50 | 1 票 |
  | 50–200 | 3 票 |
  | 200–500 | 5 票 |
  | 500+ | 10 票 |

- 未达门槛时**回落 AI 生成例句**（注明「AI 生成」），广场本身不展示 AI 内容

### 5. 与导词推荐的关系
- **两者完全独立**：广场是社交浏览页，导词推荐是实用工具
- 数据单向流动：广场产生数据 → 导词推荐消费数据
- 用户可只用其中一个

### 6. 内容审核
- DeepSeek 批改时同步返回 `is_nsfw` 字段（同一次调用，零额外成本）
- `is_nsfw: true` → 修正句正常展示给用户（私人练习不限制），「公开」按钮静默隐藏
- 广场每张卡片加举报按钮，累计 N 次举报自动隐藏待审（早期 N=3）

## 冷启动分析

功能无冷启动死亡风险，因为 AI 兜底从第 1 个用户起始终可用。

| 总用户数 | 社区句体验 |
|---|---|
| < 100 | AI 例句为主，广场句稀少但存在 |
| 100–250 | 社区句覆盖常用词，功能「成立」 |
| 250–500 | 同一词有多条社区句可比较，广场有竞争感 |
| 500+ | 社区自驱，门槛调高，质量提升 |

语言用户比例假设（目标语言）：英:中:日:法 = 3:3:2:2

## 数据模型影响

现有表需新增字段：
```
output_entries
  + is_public       BOOLEAN DEFAULT FALSE   -- 用户是否公开到广场
  + translation     TEXT                    -- 母语翻译（批改时生成）
  + upvote_count    INTEGER DEFAULT 0       -- 夯票数（冗余缓存，避免实时 COUNT）
  + is_nsfw         BOOLEAN DEFAULT FALSE   -- 批改时 DeepSeek 返回
```

新增表：
```
sentence_upvotes                            -- 防止同一用户重复点夯
  id          SERIAL PRIMARY KEY
  entry_id    INTEGER FK → output_entries.id
  user_id     INTEGER FK → users.id
  created_at  TIMESTAMP
  UNIQUE (entry_id, user_id)
```

## 衍生功能

### 「一起记」— 词库购物车
- 用户在广场看到喜欢的句子，点「一起记」→ 该词 + 社区例句直接进自己的 SRS
- 例句来源标注「来自 @某某 · 社区」，无需额外生成，**零 token 成本**
- 效果：词库跨用户互相启发，共同生长；社区句的使用次数可作为热度指标

### 点夯激励 — 换取 DeepSeek token 额度
- 每次点夯 → 赠送点击者少量额外 token（如 +500 tokens/夯）
- 上限：每日通过点夯获得的额外 token ≤ 基础日额度（最多翻倍，防止互刷）
- 效果：鼓励浏览广场、鼓励参与评分、形成"写好句→获夯→作者得 token"正向飞轮
- 反刷机制：同一用户同一句子只能点一次夯（已有 `sentence_upvotes` 唯一约束）；异常批量点夯可设频率限制

## 明确不做（P2 范围内的限制）

- 广场不出现 AI 生成内容（只有真人句）
- 不做负面/中性标签（只有「夯」）
- 不做句子编辑（公开后即定稿）
- 跨语言翻译入池暂缓（需另设验证机制，不自动入池）
