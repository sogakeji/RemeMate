## P0：Practice 上线后优化

- **语音质量与选择**：对浏览器可用 voice 做稳定排序，允许用户选择并记住 voice/语速；先改善客户端
  `speechSynthesis`，再根据真实反馈决定是否引入服务端或云端 TTS。
- **多语言扩展**：当前严格限定法语。先建立语言配置和动态 voice locale，再逐语种补题目匹配、评分、
  Unicode/标点和语音可用性测试；英语等西文优先，中文/日文单独处理无空格边界。
- **生产反馈闭环**：优先修复 Practice 的崩溃、错题选择、状态丢失、RLS 或数据隔离问题；音质与低风险
  UI 反馈按批次处理。

## P0：AI 稳定性与额度正确性

- **未完成批改不扣完成额度**：造句修改/批改在 provider 超时、`invalid_schema`、解析失败或最终未返回可用
  结果时，不得消耗用户“已完成 AI 用量”上限；provider 实际 token 成本与用户完成额度分开记录。
- **重试与幂等**：为批改请求补失败回归、有限重试和幂等扣减，避免同一请求重复记账；并验证并发额度扣减
  的原子性。
- **脱敏观测**：记录失败阶段、provider、错误分类和安全的用量字段，不记录用户正文、密钥或原始 token。
