# RemeMate 常见问题图文文档（FAQ）大纲

> 日期：2026-08-17
> 定位：面向新用户的功能级 FAQ 图文文档，目标是把使用门槛降到最低——每个功能都回答「这是什么、怎么用、在哪里、出问题怎么办」。
> 存放：正文与截图统一放在本目录 `docs/FAQ/`；截图在 `docs/FAQ/images/`。
> 边界：只写当前产品已实现的功能（详见文末「可写事实」），不承诺未上线能力；截图来自测试新云机（staging.rememate.com，非生产）。

---

## 0. 文档目标与读者

- 读者：第一次接触 RemeMate 的新用户、被邀请的语伴、使用中遇到问题卡住的老用户。
- 一句话定位（全文开头，中英各一句）：
  - 中文：RemeMate 帮你把真实遇到的词留下来、记住、并真正用出去——收词 → 复习 → 输出。
  - English: RemeMate helps you capture words you actually meet, remember them, and use them — collect, review, output.
- 组织方式：按用户旅程分 8 节，每节一组问答；每个功能性问题配 1 张截图（或一组步骤截图）。
- 每个问答固定四段式：一句话结论 → 功能解释（怎么用/在哪） → 注意事项 → 故障怎么办（若有）。

## 1. 入门与账号

1.1 RemeMate 是什么？适合谁？
- 结论：把「背词表」换成「收真实遇到的词 → 间隔复习 → 造句/日记/语伴复盘输出」的个人学习工具。
- 截图：首页 Landing（中文）。

1.2 怎么注册和登录？
- 注册 → 邮箱验证 → 登录；忘记密码怎么重置。
- 截图：注册页、登录页、（可选）验证邮件提示。
- 注意：注册入口由运营开关控制，开关关闭时只显示登录。

1.3 界面语言和学习语言怎么设置？
- 界面：中文/English 切换（右上角语言切换）。
- 学习语言：AI 支持中/英/法/日/韩/西；阅读器支持中/英/法/日；设置页选择母语与目标语言。
- 截图：设置页语言区。

1.4 有哪些入口？手机上能用吗？
- 网页应用，浏览器即可用；无需安装 App；移动端有响应式布局。
- 截图：（可选）移动端宽度的首页。

1.5 忘了密码 / 收不到验证邮件怎么办？
- 重置密码流程；检查垃圾箱；重新发送验证邮件；仍不行找管理员。
- 截图：忘记密码页。

## 2. 收词：把遇到的词留下来

2.1 有哪些收词方式？
- 手动添加、AI 填充、文本/CSV/PDF 导入、阅读中收集、会话中随手记（SessionPad）、语伴反馈包收词。
- 截图：词库列表页（或一张汇总图）。

2.2 手动添加一个词，需要填什么？
- 词条 + 语境（原句）+（可选）释义/笔记；AI 可一键填充例句和笔记。
- 截图：添加词页（含 AI 填充按钮）。

2.3 导入：文本 / CSV / PDF 怎么用？
- 导入来源 → 自动提取候选词 → 逐条审核（接受/忽略）→ 提交入库。
- 截图：导入页 → 候选审核页（2 张）。

2.4 阅读中怎么收集？
- 粘贴/上传文章 → 点击生词查询释义 → 一键加入候选 → 回词库。
- 截图：阅读页 + 生词查询卡片。

2.5 候选词是什么？为什么要审核？
- 候选是「待定」状态：审核后真正进词库并参与复习；避免垃圾词进复习。
- 截图：候选审核页。

2.6 SessionPad 是什么？
- 和语伴交流时随手记：帮自己记（进自己的候选词）、帮他记（整理成反馈包发给对方）。
- 截图：SessionPad 候选页。

2.7 词库页能做什么？
- 分语言词库、编辑/删除/标记、查看例句与笔记、n+1 词、词条详情。
- 截图：词库列表 + 词条详情（2 张）。

## 3. 复习：让词活下来

3.1 复习是怎么安排的？
- 间隔重复（SRS）：到期才出现；今天复习数量显示在首页。
- 截图：首页任务卡 / 复习入口。

3.2 复习时怎么打分？按钮代表什么？
- 记住/模糊/忘记等分级；打分决定下次间隔。
- 截图：复习卡片页。

3.3 AI 短故事是什么？怎么用？
- 把你快忘的词编成一段小故事，读完顺手练输出；生成失败时可重试。
- 截图：短故事页。

3.4 手机提醒（Bark）是什么？
- 每日复习提醒推送；设置页填写 Bark key，可测试发送。
- 截图：设置页推送区（可选）。

3.5 复习完的词去哪里了？历史怎么看？
- 复习记录、统计页（/stats）看进度。
- 截图：统计页。

## 4. 输出：真正用出去

4.1 造句怎么用？
- 从待复习/标记词里选一个词，写一句话；AI 可辅助批改/给例句；可发布到句子广场。
- 截图：造句页。

4.2 三行日记是什么？
- 用刚学的词写三行日记，短平快练输出；AI 可批改。
- 截图：三行日记页。

4.3 AI 批改怎么工作？会替换我的句子吗？
- 批改是建议不是改写；原文保留；只消耗配额不改变你的词库。
- 截图：批改结果对比。

4.4 句子广场是什么？
- 公开的句子展示与点赞；发布前可确认。
- 截图：句子广场页。

4.5 输出后如何回到收词/复习？
- 短故事 → 造句 → 保存/发布 → 继续复习的闭环。

## 5. 语伴与复盘

5.1 语伴功能是什么？和普通社交有什么区别？
- 私人的一对一语言伙伴关系，不是公开社交；围绕一位语伴做复盘与反馈。
- 截图：语伴列表页。

5.2 怎么邀请 / 绑定语伴？
- 生成邀请链接 → 对方打开链接确认 → 绑定。
- 截图：邀请创建页 / 邀请确认页。

5.3 复盘（Recap）是什么？
- 帮自己记：想记住的词句、自然说法、私人笔记（默认私有）。
- 帮他记：筛选后才生成反馈包发给对方。
- 截图：复盘表单页。

5.4 反馈包（Feedback Packet）怎么用？
- 对方收到的是快照副本；可致谢，也可挑词收进自己的词库。
- 截图：反馈包收件箱 / 详情页。

5.5 隐私边界是什么？
- 私人伙伴笔记不发 AI；对方看不到你的词库和历史复盘；「帮自己记」默认私有。
- 截图：（可选）隐私说明或复盘页私有标识。

## 6. 学习语言与界面语言

6.1 支持哪些语言？
- 界面：中文 / 英语；AI：中/英/法/日/韩/西；阅读器：中/英/法/日。
- 截图：设置页语言区（复用 1.3）。

6.2 换学习语言会丢数据吗？
- 词库按语言分开；切换语言只是入口变化，数据不动。
- 截图：词库语言筛选。

6.3 德语/俄语等旧语言为什么看不到了？
- 历史兼容保留，新入口隐藏；不影响既有数据。

## 7. 配额、数据与隐私

7.1 AI 功能有配额吗？怎么算？
- 每日 token 配额；AI 填充、批改、短故事、复盘生成等消耗配额；第二天重置。
- 截图：（可选）配额提示/耗尽提示。

7.2 配额用完了怎么办？
- 当天等待重置；或联系管理员调整。
- 截图：配额耗尽提示（若有）。

7.3 我的数据安全吗？
- 数据隔离（RLS）、敏感字段加密；私人笔记不参与 AI 总结；不写「免费注册永远开放」（开关可改）。
- 无截图（文字说明为主）。

7.4 可以把数据带走吗？
- 当前导出能力如实说明（若未提供导出，则写「暂不提供导出」，不承诺）。

## 8. 故障排查

8.1 AI 生成失败 / 报错怎么办？
- 常见原因：配额耗尽、网络、provider 波动；重试即可；反复失败联系管理员。
- 截图：失败提示（若有）。

8.2 短故事中文/法文偶尔生成失败？
- 有界重试机制；多语种仍在优化；失败不丢数据。
- 无截图。

8.3 验证邮件收不到？
- 查垃圾箱、稍等重发、检查邮箱拼写；仍失败找管理员。
- 截图：注册页验证提示。

8.4 Bark 推送没收到？
- 检查 key、测试发送、确认今天有复习任务。
- 截图：设置页 Bark 测试（可选）。

8.5 阅读器查不到某语言词典？
- 阅读器仅支持中/英/法/日；其他语言建议用收词其他方式。
- 无截图。

8.6 页面打不开 / 报 500？
- 刷新重试；确认网络；仍打不开联系管理员（附上错误信息）。
- 无截图。

## 10. 写作约束

- 只写当前产品已实现功能；不写 SessionPad 为聊天室/App、不写实时协作、不写口语打分。
- 每句能指回页面或文档事实；不承诺未做能力（导出、开放注册永久、德语/俄语新入口等）。
- 中英成对，不必逐句对译；术语统一：收词/复习/输出、语伴/复盘/反馈包。
- 正文禁止原始 HTML；只用受控 Markdown 子集（标题、段落、列表、链接、加粗、代码、图片）。
- 内链只走公开页（`/`、`/qa`、`/blog` 等）或本文档内部锚点。
- 截图 alt 必填；图片路径只落在 `docs/FAQ/images/`。
